# Course Reflection

The most difficult concept for me to master during this course was understanding asynchronous state management and cache invalidation patterns (such as Redis cache-aside strategies). Initially, wrapping my head around eventual consistency and ensuring that cached data correctly clears upon database writes felt abstract. I overcame this by breaking down real-world request flows line-by-line and mapping out how modifications propagate across replicas and caches.

Coding especially handling and understanding APIs was another challenge. Coding needs plenty of time and exercise.

Based on the feedback received during my capstone review, I would improve my architecture documentation by explicitly detailing edge-case failure recovery paths, such as handling payment gateway dropouts mid-checkout.

Moving forward, I plan to deepen my technical expertise by building full-stack backend services with Node.js and Express, implementing relational databases in PostgreSQL, and exploring cloud deployment workflows on Microsoft Azure.

I will create time to do hands on coding, building websites and building my portfolio in github to familiarize myself with all the important tools for better production.
